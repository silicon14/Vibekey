## 三、为什么自动化注入触发不了热键（已从源码确认）

`crates/vibekey-win/src/hook.rs` 的 `keyboard_proc` 里：

    // Our own injected input must never trigger a hotkey.
    if keyboard.flags & LLKHF_INJECTED != 0 {
        return next();
    }

所以 `SendInput`/`keybd_event` 合成的按键**永远**不会触发热键（这是防止自注入回环的正确设计）。
之前用合成 Alt+1 试了十几次都没反应，真键盘一次就成功，原因就在这里。

为了能自动回归，debug 构建加了一个测试口子（release 里是 `#[cfg(debug_assertions)]`，不会生效）：

    set VIBEKEY_TEST_INJECTED=1
    target\debug\vibekey.exe

此时合成按键可以触发热键，日志会打一行 WARN 提示。

**注意：** 屏幕锁定时（`LogonUI`/`LockApp` 在跑、`GetForegroundWindow()` 返回 0）任何输入都到不了窗口，
自动化脚本必须先确认桌面未锁定——本轮测试后半段就是因为锁屏而无法继续。
